# createRoot

## Summary

Creates a virtual root for a host container element.

## Signature

```ts
function createRoot(container: HTMLElement, options: VirtualRootOptions): VirtualRoot

```

## Parameters

### `container`

Host element to render into.

### `options`

Root configuration.

## Returns

A virtual root controller.
