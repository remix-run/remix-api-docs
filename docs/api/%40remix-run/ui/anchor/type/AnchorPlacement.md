# AnchorPlacement

## Summary

Main-side and top/bottom edge alignments. `AnchorOptions` also accepts left/right edge alignments.

## Signature

```ts
type AnchorPlacement =
  | 'top'
  | 'bottom'
  | 'left'
  | 'right'
  | 'top-start'
  | 'top-end'
  | 'bottom-start'
  | 'bottom-end'

```
